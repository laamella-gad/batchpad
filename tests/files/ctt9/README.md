# CTT V9 test files

Made by hand for the tests (CharPad C16 Pro 3.x writes this version); nothing
here comes from the commercial releases. Layout: `docs/charpad.md`.

- `text-mc-tiles.ctt`: multicolour text, colour per tile, 2 x 2 tiles (2 tiles,
  3 chars), a 3 x 2 map, tile tags 5 and 9, names `wall` and `sky`, key map 3, TED colours
  `$02 $35 $4a $00` as chip colours and `$71` as project colour.
- `bitmap-mc-project.ctt`: multicolour bitmap, colour per project, no tiles,
  2 chars, a 2 x 2 map, key map 10; project colours `$23` and `$5c`.
